6. Verifying this report independently

Every claim above is checkable on any Bitcoin node with the chain, without a wallet or an index.

  1. Proofs. For each bundle in ledger/: bip322-audit verify ledger/<bundle>/proofs.json. It checks every signature against its address, the stamp block, and that each listed output existed at the stamp with the stated amount (and, for outputs spent since, that they were unspent at the stamp). A second opinion on any signature: bip322-refcheck ADDRESS SIGNATURE MESSAGE runs independent implementations beside it.
  2. Balances. Each closing output: bitcoin-cli gettxout TXID VOUT; each opening output, and any spent since: the creating transaction by txid and block.
  3. Movements. Each transaction by txid, with the inputs and outputs listed in section 2.
